# HyperDrop builds

Release builds of [HyperDrop](https://gethyperdrop.com): share big files from your own server.

This repository holds no source code, only the builds, under
[Releases](https://github.com/hyperdrophq/hyperdrop-releases/releases). The same files are on gethyperdrop.com, which is
where the apps download and update from. The server is open source at
[hyperdrophq/hyperdrop-server](https://github.com/hyperdrophq/hyperdrop-server), and its builds are on that repository's releases.
